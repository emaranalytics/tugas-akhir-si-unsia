❓ Petunjuk Penggunaan / How to Use

  1. Pilih tab (Baseline / Tool Registry / Tool RAG / Perbandingan)
    Select a tab to explore each approach
  2. Pilih query contoh dari dropdown — query nyata dari dataset eksperimen
    Select a sample query from the dropdown — real queries from the experiment dataset
  3. Klik ▶ Jalankan untuk animasi otomatis, atau klik Berikutnya ▶ untuk maju langkah demi langkah
    Click ▶ Run for auto-play, or ▶ Next to step through manually
  4. Perhatikan panel Katalog Tools di bawah — kartu yang terang = terlihat LLM; abu-abu = tidak terlihat
    Watch the Tools Catalog panel — bright cards are visible to LLM; grey = filtered out
  5. Tab Perbandingan menampilkan analisis lengkap ketiga pendekatan
    The Comparison tab shows full analysis of all three approaches
