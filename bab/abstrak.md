# ABSTRAK
Pertumbuhan katalog *tool* pada AI Agent multi-modul menimbulkan masalah *tool overload*: seluruh definisi *tool* dikirim ke LLM sehingga konsumsi token meningkat proporsional terhadap ukuran katalog dan akurasi menurun akibat *context rot*. Penelitian ini merancang, mengimplementasikan, dan mengevaluasi Tool Registry deterministik berbasis metadata sebagai lapisan penyaringan *tool* sebelum inferensi pada platform ERP restoran zerlo.id. Registry menyaring *tool* berdasarkan modul, peran, tingkat langganan, kata kunci, dan anggaran token dengan batas 15 *tool* per panggilan. Evaluasi menggunakan pendekatan *Design Science Research* dengan 100 kueri berbahasa Indonesia, tiga pengulangan, dan tiga skenario katalog (30, 100, dan 300 *tool*) pada Gemini 2.5 Flash Lite, total 558 rekaman, diuji dengan Wilcoxon *signed-rank*, Cohen's d, dan *confidence interval* 95%. Hasil menunjukkan penghematan token 63–95% yang signifikan secara statistik (p<0,001; Cohen's d 11,7–782) dengan jumlah *tool* terlihat tetap konstan pada 15 meskipun katalog tumbuh sepuluh kali lipat, membuktikan skalabilitas *sub-linear* O(1). Akurasi pemilihan *tool* meningkat +6,3 poin persen sebagai tren *directional*. Tool Registry memungkinkan AI Agent enterprise diskalakan ke ratusan modul tanpa lonjakan biaya inferensi maupun degradasi konteks.

**Kata Kunci :** AI Agent, efisiensi token, function calling, skalabilitas, tool registry

# ABSTRACT
The growth of tool catalogs in multi-module AI Agents causes *tool overload*: all tool definitions are sent to the LLM, so token consumption scales proportionally with catalog size and accuracy degrades due to *context rot*. This research designs, implements, and evaluates a deterministic metadata-based Tool Registry as a tool-filtering layer prior to inference on the zerlo.id restaurant ERP platform. The registry filters tools by module, role, subscription tier, keywords, and token budget, capped at 15 tools per call. The evaluation follows the *Design Science Research* approach using 100 Indonesian-language queries, three repeats, and three catalog scenarios (30, 100, and 300 tools) on Gemini 2.5 Flash Lite, totaling 558 records, tested with the Wilcoxon *signed-rank* test, Cohen's d, and 95% *confidence intervals*. The results show a statistically significant token reduction of 63–95% (p<0.001; Cohen's d 11.7–782), while the number of visible tools remains constant at 15 even as the catalog grows tenfold, demonstrating *sub-linear* O(1) scalability. Tool selection accuracy improves by +6.3 percentage points as a *directional* trend. The Tool Registry enables enterprise AI Agents to scale to hundreds of modules without proportional inference-cost growth or context degradation.

**Keywords :** AI Agent, function calling, scalability, token efficiency, tool registry
