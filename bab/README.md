## Ketentuan Format (UNSIA)

- Font: Times New Roman 12, spasi 1.5
- Margin: Atas 3cm · Bawah 3cm · Kiri 4cm · Kanan 3cm
- Bahasa Indonesia baku, bentuk pasif
- Sitasi: IEEE style `[n]`
- Panjang naskah: 10–30 halaman (Bab I–V)
- Turnitin ≤ 30%
